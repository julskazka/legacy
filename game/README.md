# Игровая копия голосования

Адрес страницы: https://julskazka.github.io/legacy/game/

Эта страница повторяет дизайн исходного голосования, но использует отдельный игровой API и базу голосов:

- `/game/api/votes` — игровые голоса;
- `/game/api/vote` — сохранение игрового голоса;
- `/game/api/votes.js` и `/game/api/vote-form` — резервный транспорт Notibot.

В Amvera приложение `amvera-proxy/server.py` хранит игровые голоса в отдельной таблице `game_votes`, а основные — в `votes`. Переголосование внутри игры заменяет предыдущий игровой выбор.

`simulation.js` добавляет динамический, вычисляемый на клиенте прирост к игровым голосам пяти заданных номинантов до 21 ноября 2026 года, 23:59 МСК. Эти автоматические добавления не создают записей в SQLite. Ссылка на основное голосование и его серверные подсчёты остаются без изменений.

**Развёртывание:** чтобы игровые нажатия сохранялись, на Amvera должна работать обновлённая версия `amvera-proxy/server.py` (включает маршруты `/game/api/*` и таблицу `game_votes`). Обновления в GitHub сами по себе не доказывают, что Amvera уже развернула новый код.

Проверка API после развёртывания: `https://nasledie-vote-julskazka.msk1.amvera.tech/game/api/health`. Для проверки сохранения используй интерфейс игры, не основной адрес голосования.
