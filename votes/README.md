# Голоса премии «НАСЛЕДИЕ XXI века»

В этой папке подготовлено хранение на GitHub.

- `votes.json`: соответствие идентификатора Notibot → номинант и время последнего выбора.
- `worker.js`: API `POST /vote` и `GET /results`. При переголосовании заменяет прежнюю запись в `votes.json`.
- `config.js`: URL серверного обработчика; сейчас не настроен.
- `notibot-bridge.js`: получение ID из Notibot.
- `results.json`: нулевой стартовый снимок, не источник актуальных результатов.

**Рабочая запись пока не включена:** разверните Worker, настройте его секрет `GITHUB_TOKEN`, переменную `ALLOWED_ORIGIN=https://julskazka.github.io`, затем пропишите URL в `config.js`. Токен не помещайте в HTML/JS публичного сайта.

**Ограничение:** ID, полученный из приложения браузером, пока не подтверждается подписью Notibot на сервере. До подключения официальной проверки личности эта схема не защищена от подмены ID.

**Публичность:** репозиторий `legacy` открыт, поэтому ID и история их изменений станут публичными, если хранить их прямо в `votes.json`.
