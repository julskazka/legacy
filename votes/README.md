# Голосование «НАСЛЕДИЕ XXI века» — GitHub

**Публичная страница:** https://julskazka.github.io/legacy/

## Текущая реализация

- HTML получает Telegram ID из Notibot (или MAX/Notibot ID, если Telegram ID не передан).
- При подтверждении голос отправляется **не на сторонний сервер**, а напрямую в GitHub REST API.
- GitHub изменяет `votes/votes.json`: один ID → один действующий номинант; при повторном голосовании прежний выбор перезаписывается.
- Страница читает файл и подсчитывает реальные голоса; топ-5 формируется из этого же реестра.
- При одновременном голосовании запрос повторяется, если SHA файла изменился.
- После успешной записи GitHub возвращает подтверждение коммита; только тогда появляется окно «Спасибо».
- Голосование заканчивается 21 ноября 2026 года в 23:59 МСК.

## Одно обязательное действие для включения сохранения

В [`votes/config.js`](config.js) необходимо заполнить `window.NASLEDIE_GITHUB_TOKEN` действительным токеном GitHub (fine-grained personal access token) для **julskazka/legacy** с разрешением **Contents: Read and write**. Других серверов нет. Токен здесь не заполнен, поэтому сейчас запись с публичной страницы **не активна**.

**Внимание:** токен в публичном JavaScript доступен любому посетителю; GitHub может отозвать раскрытый токен. Такой способ выбран по запросу владельца и не подходит для защищённого голосования.

## Где хранятся голоса

- `votes/votes.json` — текущие голоса, формат `{"tg:12345":{"nominee_id":7,"updated_at":"..."}}`.
- `index.html` — карточки, кнопки голосования, счётчики и рейтинг.
- `votes/notibot-bridge.js` — получение идентификаторов.
- `votes/config.js` — параметр доступа GitHub.
- `.github/workflows/save-vote.yml` — резервный вариант записи через GitHub Actions, **не используется HTML при прямой записи**.

`votes/results.json` — устаревший нулевой снимок, не источник результатов.
