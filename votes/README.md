# История голосования — НАСЛЕДИЕ XXI века

Эта папка предназначена для серверно сформированной истории голосов и агрегированных итогов, а не для записи напрямую из HTML на GitHub Pages.

## Формат
- `results.json`: агрегированные количества голосов по ID номинантов, время обновления. Только серверный обработчик может публиковать этот файл.
- Индивидуальная история голосов с идентификаторами участников **не должна публиковаться в открытом репозитории**. Её следует хранить в закрытой базе или закрытом репозитории, доступном серверу.
- При повторном голосовании один проверенный пользователь имеет только один действующий голос; новая запись заменяет старый выбор атомарно.

## Перед включением
1. Получить официальную схему подтверждения личности/подписи Notibot из приложенной документации.
2. Реализовать серверный endpoint для проверки запроса, записи голоса и чтения результатов.
3. Хранить GitHub-токен только в серверных секретах (не в `index.html`).
4. Подключить `index.html` к endpoint и проверить с двумя пользователями, повторным голосованием и перезагрузкой.

До прохождения этих пунктов интерфейс не должен сообщать, что реальный голос учтён.
