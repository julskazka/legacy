# НАСЛЕДИЕ XXI века — голосование

Файл `index.html` — утверждённая мобильная версия интерфейса голосования премии «НАСЛЕДИЕ XXI века».

## Публикация
Для включения GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.

Предполагаемый адрес после включения Pages: https://julskazka.github.io/legacy/

## Важно: голосование пока демонстрационное
Текущая версия использует `localStorage` браузера. Это **не общая база голосов**, не защита от повторного голосования и не интеграция с Notibot. Реальные результаты/топ-5 использовать нельзя.

Перед запуском реального голосования необходимо:
1. Проверять пользователя на серверной стороне по достоверным идентификационным данным Notibot (не доверять ID, присланному только из HTML).
2. Хранить один действующий голос на пользователя; при смене номинанта обновлять запись атомарно.
3. Получать итоговые счётчики и рейтинг только из серверной базы.
4. Хранить секреты Notibot и базы **в закрытых переменных окружения**, не в GitHub Pages/HTML.
5. Проверить доступные API/подписи Notibot до реализации.

Нельзя сохранять записи голосов напрямую в публичный GitHub-репозиторий: история коммитов открыта, GitHub Pages не выполняет серверный код.
