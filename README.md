# НАСЛЕДИЕ XXI века — голосование

Файл `index.html` — согласованный мобильный интерфейс без демонстрационного режима.

## Публикация страницы
GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`.
Адрес после включения Pages: https://julskazka.github.io/legacy/

## Хранение голосов в GitHub
- `votes/votes.json` — записи голосов по ID участника Notibot (один пользователь → один выбранный номинант).
- `votes/worker.js` — серверный обработчик, который обновляет GitHub через Contents API.
- `votes/config.js` — адрес развернутого обработчика.
- `votes/notibot-bridge.js` — интеграция получения ID в приложении Notibot.
- `votes/results.json` — первоначальная заготовка агрегатов; актуальные результаты обработчик рассчитывает из `votes/votes.json`.

**ВНИМАНИЕ:** Для работы необходима отдельная публикация серверного обработчика (например, Cloudflare Worker), запись его URL в `votes/config.js` и настройка серверного секрета `GITHUB_TOKEN`. Без этого голосование на странице заблокировано и голоса не отправляются. GitHub Pages — статический хостинг и сам в свой репозиторий не пишет.

Публичный репозиторий делает `votes/votes.json`, а также всю историю его изменений, доступными всем. Идентификаторы Notibot/Telegram/MAX могут относиться к персональным данным. Перед запуском следует решить вопрос уведомления пользователей и защиты от подмены ID: браузерный ID сам по себе не доказывает личность.
